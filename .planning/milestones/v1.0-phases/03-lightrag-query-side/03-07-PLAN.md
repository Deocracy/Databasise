<objective>
Build the parity harness: drive the pre-decomposition original as an external pinned subprocess,
drive the decomposed arms through the machine, pin `keywords` across both, and produce a
deterministic retrieval-level comparison plus an N-run variance band over the one stochastic node.

Purpose: criterion 2 asks for a variance band rather than a single diff, and PITFALLS 2 is the reason
— temperature zero is not determinism, and a one-shot check that happens to agree gets treated as
proof of equivalence. D-12's design gets both halves at once: pin `keywords` per query so everything
downstream is deterministic and comparable exactly, and measure `keywords` itself over N runs so the
single stochastic node's variance is isolated instead of smeared across the whole path.

Output: a runnable comparison the owner invokes from a shell, producing a machine-readable result and
a human summary, with `inconclusive` as a first-class outcome.
</objective>
