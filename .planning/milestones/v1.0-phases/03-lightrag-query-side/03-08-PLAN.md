makes the audit an artifact emitted from the run record instead, and an undeclared touch a refusal
rather than a report line.

## Flagged planner assumptions

- **Unresolved probe edge — MODAL-01.** Classified `unclassified`, therefore `unresolved`. Recorded,
  not auto-resolved and not dropped.
- **Touch recording is placed in the scheduler's scoped views.** CONTEXT.md leaves the audit's
  mechanism open beyond "emitted from the run record". The scoped views are the only place that knows
  both the node id and the requested handle; a proxy around the raw stores cannot attribute a call to
  a node. This is the planner's call and it is the reason `scheduler.py` appears in this plan's
  `files_modified` a second time this phase.
- **The `w1` rewrite uses the real `local` arm.** The wiring's own title says "Decomposed
  lightrag-local query side", so `local` is the arm its content should be. If the executor finds the
  `local` arm's node set makes an existing probe assertion untestable, that is the verdict-change
  signal Task 3 describes, not a licence to pick a different arm.
- **The Falsifier 2 verdict is expected to hold but is not assumed to.** Task 3's stop condition is
  written to be triggered, not decorative.
