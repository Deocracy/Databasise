Add `scipy>=1.11` to `databasise/pyproject.toml`'s `[project] dependencies`, cleared by 06-01 Task 1's legitimacy checkpoint. Run `uv sync`.

Create `databasise/eval/calibration.py` following `run_comparison.py`'s harness shape: pure functions over inputs, a machine-readable result object and a human-readable summary, and a pre-flight verification gate before any number is trusted — the same D-02 pattern that module already establishes, applied here to the cache-bypass precondition.

`NullIdentity` is the frozen key a null is stored and read under: `bundle_at_v`, `tier`, `metric`, `determinism_setting` and `concurrency_setting`. §AA.1 makes the settings part of the null's own identity rather than a label two nulls may share, so they are members of the key, not metadata beside it.

`paired_differences(run_a, run_b, metric)` produces the n per-question differences from two runs of the same arm — the arm run against itself, twice — refusing when the two runs do not cover the same question set, since a paired statistic over unequal sets is not paired.

`calibrate_aa_floor(paired_diffs, *, n_resamples, seed)` bootstrap-resamples with replacement using `scipy.stats.bootstrap` with `paired=True` and `method="percentile"`, and returns the resampled distribution's p95 as the floor. Do not hand-roll the resampling loop: §AA.1 explicitly reuses "the paired-bootstrap machinery §5 already specifies" and mints no new statistical apparatus, and `scipy`'s implementation already handles the tie and degenerate-resample edge cases a hand-rolled version gets wrong. Default `n_resamples` to 2000 and record the value used in the result — 06-RESEARCH's assumption A3 flags this as unstated anywhere in the project record, so it is recorded rather than assumed.

The boundary rule is a method on the result, not a caller convention: `clears_floor(delta)` returns true only for a delta strictly above the floor. §AA.1 resolves this explicitly — a delta sitting exactly at the p95 mark is a value the null already produces five percent of the time, and treating it as sufficient would treat the null's own upper tail as if it lay outside the null.

The cache-bypass precondition is a hard gate, not a warning. `calibrate_aa_floor` takes the two runs' own `RunRecord` node traces and refuses with `UnusableFloorError` when any node reports a cache hit, and equally when the bypass status cannot be established at all — §AA.2's "a null whose bypass status is unknown is not usable as a floor", which is a refusal to calibrate, not a caveat attached to a published number. State in the module docstring why this is a correctness risk and not an efficiency one: a cache-served re-run cannot differ from itself, so the resulting null is near-zero-width and the floor derived from it is too permissive, and it looks tight, well-behaved and cheap while being wrong.

`StaleNullError` fires on any of §AA.1's four invalidating events and names which one applies, so a caller reads a cause rather than a bare refusal. This is the concrete implementation of §5's fourth refusal condition; say so in the docstring rather than leaving the link to be inferred.

`correct_for_batch_width` implements §AA.3's two tiers, and the module docstring states the nesting explicitly because Pitfall 5 names conflating them as the live hazard: Benjamini-Hochberg FDR across the N candidate arms within one batch, producing at most one decision per batch; then §5's epoch-level correction across the resulting per-batch decisions. The two operate on distinct populations and neither corrects the same comparison twice. Implement the escalated-survivor tier as Holm step-down, and record in the docstring that §AA.3 names Dunnett-style as preferred where a resampling implementation is practical and Holm as the stated fallback — Holm is chosen here as the fallback §AA.3 itself names, not as a substitute for a correction the record did not consider.

Write `databasise/tests/eval/test_calibration.py` covering the `<behavior>` block. Test 6's negative control is required: without it a bootstrap that ignored its input and returned a constant would pass every other assertion.
