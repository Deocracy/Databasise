  <action>
    Write `databasise/stores/blob.py` as a content-addressed filesystem store — D-06 gives blob to
    the filesystem, and this is a new primitive with no v1 incumbent.

    Fan-out layout, decided here and recorded in the module docstring as a Claude's-Discretion
    choice: two levels of two hex characters each, so a digest `abcd1234...` lands at
    `<namespace_dir>/blobs/ab/cd/abcd1234...` carrying the full 64-character digest as the filename.
    Git's own object store uses one level; two keeps the leaf directory count bounded well below any
    filesystem's practical per-directory limit for a multi-million-blob store, at the cost of one
    extra directory level. State the number of levels explicitly so a future reader changing it
    knows it is a layout change requiring migration, not a tuning knob.

    `put(content: bytes) -> str` hashes the content, computes the path, and writes only if the path
    does not already exist — identical content already stored is a no-op, never an overwrite and
    never an error. Write to a temporary file in the same directory and `os.replace` into position
    so a partially-written blob can never be observed at its final path.

    `get(digest) -> bytes` raises a named `BlobNotFoundError` on an unknown digest. `read_range(
    digest, offset, length) -> bytes` seeks and reads the requested range, raising on a range that
    extends past the blob's length rather than returning short data — this is the operation CONTRACT
    §2's `reads_blob` amendment was added for, so it exists from Phase 1 rather than being retrofitted.
    `delete(digest)` removes the file and is a no-op on an absent digest, and prunes an emptied
    fan-out directory only if pruning cannot race a concurrent `put` — if it can, leave the empty
    directory rather than risk it.

    Implement the same lifecycle ABC as the other adapters. The blob store's `index_done_callback`
    is a no-op by nature (content-addressed writes are already atomic), but implement it explicitly
    with a docstring saying so, rather than inheriting a default that a reader would have to go
    looking for.
  </action>
