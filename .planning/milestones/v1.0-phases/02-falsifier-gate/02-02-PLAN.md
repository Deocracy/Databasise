<objective>
Record MACH-09's default measurement posture as a checkable artifact and pin the structural fact
that makes it true today, without inventing a configuration surface no code reads.

Purpose: MACH-09 requires that answer-level and index-side measurement stays off by default and
that fallback runs are labelled `degraded` with a `degradation_reason`. The labelling half is
already built and tested (Phase 1, `databasise/runner/trace.py`). The default-off half holds today
because no measurement-gated promotion path exists anywhere in the package — a fact worth pinning
so a later phase must change the posture deliberately rather than by accident.

Output: a posture record under `.planning/phases/02-falsifier-gate/` and one guard test module.
</objective>
