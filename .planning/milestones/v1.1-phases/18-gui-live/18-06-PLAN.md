Facts this plan relies on:
- EvidenceRef is `{ref, namespace, kind, score, tier}`. The server refuses a body with `id` as `extra_forbidden` with `missing ref`. An unknown ref is 404 `UnresolvableEvidenceReferenceError`. A HippoRAG record is `{id, document_id, ordinal, content}`; a LightRAG record is `{id, full_doc_id, content, file_path}`.
- Trace shapes: the non-debug keys are `arm_execution_order, bundle_ref, concurrency_setting, corpus_snapshot_hash, degradation_reason, degraded, determinism_setting, executor_version, partial, stop_reason`; debug adds `arm_id, nodes[], run_id, wiring_id, wiring_instance_hash`. An unknown trace is 404 `UnknownTraceReferenceError`.
- The open-evidence payload from Query and Compare is `{ref: <EvidenceRef unchanged>, score, trace_token}` (18-04, 18-05). 18-10 emits the same shape from the chunk browser.
- Ids: `evidence.inspector.*` (content, document-link, trace-link, score), `evidence.lookup.*` (ref with `data-field-loc="body.ref"`, namespace, kind, submit), `evidence.trace.*` (reference with `data-field-loc="body.trace_reference"`, load, recent, debug, nodes), `evidence.batch.submit`, `evidence.batch.status`, `evidence.state.*`.
- Engine methods behind the routes (rest.py:435-441): `POST /evidence/resolve` calls `engine.resolve_evidence(ref)` and `POST /trace/resolve` calls `engine.resolve_trace(trace_reference, debug=...)`. `LiveApp.hold("resolve_evidence")`, `LiveApp.fail("resolve_evidence")` and the same for `resolve_trace` use these names.
