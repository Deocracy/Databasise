Facts this plan relies on (mcp SDK 2.2.0, read from `.venv/lib/python3.12/site-packages/mcp/server/mcpserver/` while planning):
- `exceptions.py`: `ToolError(MCPServerError)`; `UnexpectedToolError(ToolError)`.
- `tools/base.py` `Tool.run`: argument validation failure raises `ToolError(f"Error executing tool {name}: {exc}") from exc` with the pydantic `ValidationError` as `__cause__`; a `ToolError` from the body is re-raised as `ToolError(f"Error executing tool {name}: {exc}") from exc`; any other exception from the body becomes `UnexpectedToolError(f"Error executing tool {name}") from exc`. So the prefix cannot be removed from inside a tool body.
- `server.py` `MCPServer.call_tool(name, arguments, context=None)` delegates to the tool manager; `_handle_call_tool` awaits `self.call_tool(...)` and on any exception returns `CallToolResult(content=[TextContent(type="text", text=str(exc))], is_error=True)`, logging a non-`UnexpectedToolError` `ToolError` at INFO and anything else with `logger.exception`. Raising a `ToolError` subclass whose `str()` is the bare JSON from an overriding `call_tool` therefore yields exactly the D-02 wire result.
- `databasise/mcp/server.py`: `_refusal_detail` (lines 79-92) copies the REST body builder; `_refusal_mapped` (95-108) wraps every tool body; scope preconditions raise plain-text `ToolError` at lines 128, 161, 167; `create_server` builds `MCPServer(_ServerName)`. SDK classes are resolved through `import_sdk` (never a bare `import mcp`, which hits a CWD-shadow import cycle).
- Existing tests call `await server.call_tool(...)` with `pytest.raises(ToolError)` (10 sites, e.g. `tests/mcp/test_dual_transport_parity.py:201,224,245`, `tests/seam/test_dual_transport.py:445,493`, `tests/seam/test_hipporag_write_path.py:338`) and parse the payload from the first `{` (`_tool_error_detail`); both keep working with bare JSON. The protected growth test calls `server.add_tool(...)` and `server.list_tools()` on the object `create_server` returns, and walks the AST of `databasise/mcp/*.py` for calls to `resolve_selector`, `ResponseEnvelope` or redact helpers (none are added here).
- In-memory wire client: `mcp = import_sdk("mcp")`; `async with mcp.Client(server) as client: result = await client.call_tool("ingest", {"args": {}})`; `result.is_error`, `result.content[0].text` (research ran this against 2.2.0; `mcp.Client` exists, checked while planning).
