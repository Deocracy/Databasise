Facts this plan relies on:
- `CompareRequest.selectors` is `list[Selector]`. A `null` entry is a 422 validation error with `loc ["body", "selectors", 0]`; Default is `{}`. Two `{}` entries give 422 `DuplicateComparisonKeyError` with key `default`. One selector gives a bare envelope; two or more give a map keyed by the unprefixed comparison key (`comparisonKey` in 10-shared.js follows the same rule).
- `GET /ledger/aliases` rows are `{alias, active_version, record_kind, generation_ordinal, created_at}`, with no arm (18-RESEARCH Pitfall 8).
- An alias named `answer` is set up in a module fixture: run `live_app.query(text, HIPPORAG)`, then `live_app.promote("answer", [trace_token])`. A compare of `[HIPPORAG, {"alias": "answer"}]` then returns the keys `reads_graph+reads_kv` and `answer`; a key named `answer` must never be mistaken for the envelope field `answer`.
- `LiveApp.hold("compare")` keeps a compare in flight, and `LiveApp.fail("compare")` gives a real 500.
