<objective>
Expansion plan (RUN-02, RUN-03): harden `OpenAICompatibleClient` so a provider response with no usage is counted as one unbudgetable call (D-05), and malformed responses raise named errors or are returned in input order (D-06) — never passed on silently.

Purpose: ROADMAP Phase 8 criterion 4. Token tables stop recording a real spend as zero, and a refusal no longer becomes a blank answer.
Output: three new error classes, a one-line accounting change, eleven regression tests, one end-to-end refusal test.
</objective>
