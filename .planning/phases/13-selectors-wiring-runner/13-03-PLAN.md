<objective>
The run record reports what was measured, in a schema that admits it. The frozen trace schema rejects every new field, so Databasise adds a derived schema (the frozen file plus declared, recorded amendments) and validates against it (D-12). NodeTrace gains `status`, `execution_mode`, `spent` and `allowance`; `cache_hit`, `tier` and `feed_tier` become null when nothing measured them; and the closed reason-code set is defined (WIRE-11, D-14, D-05). The scheduler stamps the new fields at its two existing NodeTrace sites; 13-04 then restructures the dispatch loop around them.

Purpose: ROADMAP Phase 13 criterion 3 (execution_mode stamped, unreported fields null rather than guessed). D-12 must land before D-13/D-14, and the conftest flip lands in the same plan as the field additions (Pitfall 7).
Output: derived schema, deviation record, trace model fields, scheduler stamps, conftest flip, row tests.
</objective>
