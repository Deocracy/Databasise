An operator can page a modality's chunk refs, chosen by selector, and open any of them through /evidence/resolve. The read constructs nothing and reconstructs no vectors (D-14; ROADMAP Phase 16 criterion 4; CONN-10).

Output: `FaissVectorStore.list_ids`, `Databasise.chunk_page`, POST /chunks, the row file and the first store-level spy file.
Sequential: this plan runs after 16-06 on the main tree.
