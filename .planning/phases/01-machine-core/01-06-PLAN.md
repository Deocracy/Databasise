<objective>
Build the artifact registry — a SQLite index over the content-addressed blob store, carrying
CONTRACT §7's field set and distinguishing all three §3 scopes — plus the second, non-bypassable
blast-radius check at the write path, plus the append-only promotion ledger with its derived active
pointer.

Purpose: this is where MACH-08's scope rules become enforced storage rather than a validator opinion,
and where D-02's second call site closes the bypass. The ledger table is stood up now so Phase 2's
A/A calibration and trace records have somewhere to land, even though the first real promotion is
Phase 2's.

Output: an artifact registry whose scope filter is applied by the registry itself, a write path no
caller can go around, and an append-only ledger whose active pointer is a projection.
</objective>
