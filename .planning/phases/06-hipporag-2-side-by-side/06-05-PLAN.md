This is §14.2's batched self-KNN sub-capability: one Faiss search over the whole stored matrix at once, returning each stored id's top-k nearest neighbours excluding itself. Use the class's existing index object and its existing normalisation, request `top_k + 1` neighbours per row so the self-match can be dropped, and issue one batched `search` call for the whole matrix — never a loop over `query()`, and never a loop over `search`.
