<objective>
Build the one thing MACH-03 is actually missing: a runnable A/A driver.

**This gap was not in the brief, and it is real.** The record entering this round states that
MACH-03's remaining blocker is "only the spend itself." Reading the code contradicts that.
`databasise/eval/calibration.py` is a set of pure functions over a `paired_diffs` sequence, and its
only callers anywhere in the repository are its own tests — `grep -rn "calibrate_aa_floor"` returns
`databasise/eval/calibration.py` and `databasise/tests/eval/test_calibration.py`, nothing else.
`paired_differences` takes two already-computed question-id-to-score mappings, and **nothing
produces them**: no module runs an arm twice over the bundle's questions, no module scores a
response envelope against a gold document list, and no module scores a candidate answer against a
gold answer. 06-06 built the instrument and said so accurately ("the calibration procedure itself
landed… the *instrument*, not a real run"); 06-12 closed the two named preconditions (a resolved
judge identity, a cost-bounded corpus ingest). Neither built the driver between them. 06-13's own
checkpoint text describes step (3) — "two paired runs over the bundle's dev split produce
per-question differences" — as though a module performed it. None does.

**So the honest sequence is: build the driver, then ask for the spend.** This plan is the first
half and is entirely spend-free. 06-17 is the second half and holds the checkpoint.

**Two scorers, because MACH-03's pass criterion needs both.** The criterion is "per-tier null width
at T1 materially narrower than T0", which is a comparison between the two §EV.2 target families and
cannot be read from one. `gold_passage` (T1) is scored from retrieval alone — no judge, no LLM —
and is the cheap leg. `answer_level` (T0) needs one judge call per question per pass and is the
expensive leg the owner has twice declined to fund. Both scorers ship here; neither runs here.

evidence rides on, and the second of the two success criteria 06-VERIFICATION.md marks FAILED.
Output: `databasise/eval/aa_run.py`, a genuine runnable driver with a dry-run default, proven
