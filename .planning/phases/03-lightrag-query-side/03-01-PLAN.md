<objective>
Build the machine-owned client primitive D-06 requires and thread it into the node context, so
every later ported part reaches an LLM, embedding, or rerank endpoint through a boundary the
meter can see.

Purpose: MACH-05 meters spend at each node's declared boundary. A part-internal HTTP call has no
boundary the meter can see, so the client has to be a machine primitive injected alongside
`stores` before any of the seventeen ports is written. Building it anywhere else means moving it
later and touching all seventeen (D-06, rated **costly**).

Output: a `databasise/clients/` package with an OpenAI-compatible implementation, a
`CapabilityScopedClients` deny-by-default wrapper mirroring `CapabilityScopedStores`, a `clients`
field on `NodeContext`, and the scheduler/composer threading that populates it.
</objective>
