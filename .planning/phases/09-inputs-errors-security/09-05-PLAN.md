<objective>
Expansion plan (SEAM-05, SEAM-06, D-04): a v1 engine failure is a machine fault, not a caller refusal. `ForeignEngineRefusalError` becomes the one fault type on every route (ingest, delete, and the read routes GET /corpus, /corpus/counts, /jobs/{id}), carries a public `failure_class`, returns 502 (run failed or malformed output) or 503 (v1 unavailable: missing interpreter, timeout), never exposes stderr, tracebacks, server paths or env-var names, and is logged server-side in full.

Purpose: ROADMAP Phase 9 criterion 3.
Output: the reworked refusal, one engine helper that builds and logs a fault, a read-op wrapper around `run_corpus_op`, the fault statuses in `rest._status_for`, OpenAPI fault responses, and two new test files.
</objective>
