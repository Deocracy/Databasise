<objective>
Expansion plan (SEAM-01, SEAM-09): a path-like or malformed evidence namespace is refused as `InvalidEvidenceNamespaceError` before any store is opened or directory created (D-05), and empty inputs (empty or whitespace-only text, 0-byte uploads, empty or invalid base64) are refused by name instead of being run or enqueued (D-08).

Purpose: ROADMAP Phase 9 criterion 2.
Output: the namespace guard and a store-free unknown-namespace path in `resolve_evidence`, the whitespace rule in `check_consumable`, the empty-document rule in `IngestDocument`, strict base64, two refusals, a small shared test helper and two new test files.

Scope note: the 10 files stay in one plan because both input refusals go through the same refusal plumbing (`refusals.py` and the `_REFUSAL_FACTORIES` test in `test_rest_transport.py`), so a split would put two plans on those two files in back-to-back waves for no isolation gain; `_probes.py` is created here because `test_empty_inputs.py` needs it first (09-07 reuses it).
</objective>
