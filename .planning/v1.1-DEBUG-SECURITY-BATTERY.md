## Bugs fixed (24 fix commits, 23 RED tests, 2 reverts)

Server, phase 09/10/11/13/16 code:
- Response builders never raise on caller content: refusal bodies are UTF-8 safe, NaN/Infinity become null, the schema-error 422 no longer echoes `input`, and every echoed caller value is bounded (200 chars, 20 items), including evidence refs and the 422 `loc`.
- Lone-surrogate text is refused by name (new NonEncodableTextError, 422) at every input boundary before it reaches sqlite or the run-identity hasher: selectors, query text and keys, ingest text, trace references, promote trace ids and change_origin, rollback/retire version, history alias, evidence namespace.
- Bounds: document id capped at what fits a 255-byte file name with its suffix; evidence namespace capped at 128; page offset capped at 2**31-1 (named PageBoundsError); query text capped at the document byte cap; compare duplicate check linear; GET /log limit out of range is PageBoundsError.
- Stores: a refused close under an in-flight Cozo query no longer escapes as a 500 or orphans the client; the kv health probe no longer reports a healthy store as corrupted during a WAL checkpoint; v1's doc-status read moved off the event loop.
- Wiring parser reports non-string node keys instead of raising.
- Launcher and clients: empty required env values refused by name; `--port` range checked before the store lock; negative token counts from rerank, chat/embedding and v1 ingest usage are treated as unbudgetable instead of negative spend.

Console, phase 18:
- Corpus Retry is disabled with a reason while another write is in flight; the jobs poll no longer wipes error banners; the Graph screen's status line names the store the selector resolves to; the Timeline loading state clears on an invalid page size; a malformed stored history entry no longer stops the console script at start-up.
